# Engagement Invitation — Abdullah Qaisar & Hira Tanveer

Mobile-first invitation with envelope opening animation, invitation card (~70% screen height), and scroll-to-venue with maps.

## Run locally

```bash
npx --yes serve .
```

Open the URL shown in the terminal (usually `http://localhost:3000`).

Or open `index.html` directly in a browser (maps embed may need a local server).

## Customize venue

Edit `config.js`: set `name`, `address`, `lat`, and `lng` for your venue.
